# Contributing to Synn

First off, thank you for considering contributing to Synn! It's people like you that make Synn such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

## Fork & create a branch

If this is something you think you can fix, then fork Synn and create a branch with a descriptive name.

## Get the test suite running

Make sure you're using Node.js 18+ and `pnpm`.

```bash
pnpm install
pnpm dev
```

Run tests before pushing:
```bash
pnpm test
pnpm lint
pnpm format
```

## Implement your fix or feature

At this point, you're ready to make your changes. Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with Synn's master branch.
Then, submit a pull request with a clear description of the changes you've made.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
